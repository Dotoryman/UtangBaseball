# 보관 자료

현재 게임과 운영 화면에서 사용하지 않지만, 과거 제작 과정과 원본 복구를 위해 남겨 둔 파일입니다.

- `public/`: 이전 버전의 런타임 이미지와 미사용 시안
- `components/`: 현재 앱에서 가져오지 않는 UI 컴포넌트
- `scripts/`: 완료된 이전 버전 제작·검수 도구
- `assets/`: 초기 콘셉트 및 교체된 원본
- `docs/`: 완료된 과거 릴리즈 검수 기록

이 폴더는 애플리케이션 빌드와 배포에 포함되지 않습니다. 파일을 다시 사용할 때는 현재 코드에서 직접 참조하지 말고 적절한 활성 폴더로 복원한 뒤 테스트해 주세요.
