# v0.8.0 검수

- 원래 캐릭터 이미지와 야구장 유지. 시작/결과 배경은 코드 기반 엽서 구성으로 교체.
- 시작 별 위치, 결과 배경이 이모티콘을 가리는 문제를 브라우저 검수 후 조정.
- 430px 게임 영역의 시작, 상태바, 결과 화면 직접 확인.
- 홈런은 180ms 후 타구 출발, 전용 배너/느낌표, 420ms 흔들림, 2100ms 후 다음 투구. 기존 타격 성공 시 투구 제거 분기는 유지.
- 동작 줄이기 설정은 흔들림과 배너 애니메이션을 비활성화.
- lint, TypeScript, Wrangler 배포 dry-run 통과.
- 빌드 파일 및 프리렌더 생성 완료 후 기존 Windows libuv 종료 assertion 재현.
- 홈런 실플레이 자동 검수는 점수 기록 가능성을 이유로 안전 검토에서 거절되어 완료하지 못함. 성공 확인으로 표기하지 않음.
- 모바일 Safari/카카오톡 앱 실기기 검수는 미실시.
