# v0.8.1 자동 검수

테스트 브라우저는 localhost 이외 요청을 차단하며 /api/scores는 메모리 응답으로 대체한다. 운영 랭킹과 DB에는 점수를 쓰지 않는다. 난수만 고정하고 실제 화면의 공 좌표에 맞춰 브라우저 마우스로 타격한다.

## 확인 항목

- 360px / 430px: 카운트다운 중 공 없음, 상태바 숫자 폰트 통일.
- 실제 타격으로 홈런 발생, 타자 옆 강조 말풍선 표시.
- 성공 순간 들어오는 공 제거, 이후 타구만 표시, 다음 투구 전 타구 제거.
- 동작 줄이기 설정에서 흔들림 비활성화.
- 놓친 공 포수 캐치 후 공 제거.
- 게임 종료·재시작·홈 이동 정상, 브라우저 예외 없음.
- 높이 600px에서 결과 화면 휠 스크롤 후 scrollTop > 0 확인.
- 스크롤 시 장식이 내용과 함께 움직이도록 결과 패널을 배치 기준으로 설정.

재실행: QA_RUNTIME에 Playwright가 설치된 node_modules 경로를 지정하고 `node scripts/qa-v080.cjs` 실행. 결과 JSON과 화면 캡처는 `artifacts/qa-v081`에 저장된다.

실제 iPhone Safari 및 카카오톡 네이티브 앱 검수는 별도이며 이 검사로 대체하지 않는다.
