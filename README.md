# UtangBaseball · 우땅야구

[우땅야구](https://utangbaseball.cloud)는 우땅이를 좋아하는 팬이 만든 팬페이지이자, 스마트폰에서 빠르게 즐기는 7구 타격 야구 게임입니다. 공식 캐릭터의 귀여운 분위기를 게임 속 투수·타자·포수와 응원 관중 연출에 담았습니다.

> 팬이 제작한 비공식 프로젝트입니다. 우땅이 및 관련 원저작물의 권리는 각 권리자에게 있습니다.

## 개발

```bash
npm install
npm run dev
```

검사는 `npm test`, `npm run lint`, `npm run typecheck`, `npm run build` 순서로 실행합니다.
현재 폴더 역할과 이미지 제작 흐름은 [프로젝트 구조](docs/ARCHITECTURE.md)와
[이미지 도구 안내](scripts/README.md)에 정리되어 있습니다. 이전 자료는 `old`에 보관하며
실행 코드나 배포 자산으로 사용하지 않습니다.
