# UtangBaseball · 우땅야구

[우땅야구](https://utangbaseball.cloud)는 우땅이를 좋아하는 팬이 만든 팬페이지이자, 스마트폰에서 가볍게 즐기는 10구 타격 야구 게임입니다. 공식 캐릭터의 귀여운 분위기를 게임 속 투수·타자·포수와 응원 관중 연출에 담았습니다.

> 팬이 제작한 비공식 프로젝트입니다. 우땅이 및 관련 원저작물의 권리는 각 권리자에게 있습니다.

## 게임 방법

1. 닉네임을 입력하거나 비워 둔 채 `경기 시작`을 누릅니다. 빈 닉네임은 `우땅이`로 표시됩니다.
2. 투수가 던진 공이 포수 앞 ABS의 노란 원에 들어오는 순간 화면을 탭합니다. PC에서는 클릭이나 스페이스바를 사용할 수 있습니다.
3. 총 10구가 끝나면 점수, 홈런 수, 최고 비거리, 최고 콤보와 오늘 순위를 확인하고 결과 카드를 공유할 수 있습니다.

## 판정과 점수

타이밍 오차로 타구 속도와 발사각을 계산한 뒤 비거리에 따라 실제 야구 결과를 정합니다.

| 결과 | 기본 점수 | 기준 |
| --- | ---: | --- |
| 에구구! | 0 | 타격 가능 구간을 크게 벗어남 |
| 파울! | 180 | 배트에는 맞았지만 타이밍이 어긋남 |
| 내야안타! | 800 + 거리 점수 | 비거리 30m 미만 |
| 안타! | 1,200 + 거리 점수 | 비거리 30~72m |
| 2루타! | 2,100 + 거리 점수 | 비거리 73~95m |
| 3루타! | 3,000 + 거리 점수 | 비거리 96~114m |
| 홈런! | 4,500 + 거리 점수 | 비거리 115m 이상 |

거리 점수는 1m당 10점이며, 안타를 이어가면 콤보 배수가 0.1씩 증가합니다. 에구구 또는 파울 판정에서는 콤보가 초기화됩니다.

## 오늘의 우땅왕 랭킹

공용 랭킹은 Cloudflare D1에 저장되며 **매일 한국시간 00:00**을 기준으로 새로 시작합니다. 시작 화면에는 오늘의 TOP 5, 결과 화면에는 TOP 3와 내 순위가 표시됩니다. 서버 연결이 없는 로컬 개발 환경에서는 브라우저 저장 기록을 같은 기준으로 보여줍니다.

## 주요 기능

- 직구·커브·체인지업으로 구성된 10구 승부
- 투수·타자·포수의 상태별 애니메이션과 결과별 우땅이 포즈
- 회전하는 야구공, ABS 타격 가이드, 콤보와 점수 HUD
- 모바일 공유 시 점수가 들어간 PNG 결과 카드 생성
- 모바일 우선 반응형 UI와 동작 줄이기 접근성 지원
- Cloudflare Workers + D1 및 공식 도메인 배포
