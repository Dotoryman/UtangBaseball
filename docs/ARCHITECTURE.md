# 우땅야구 구조

## 실행 코드

- `app/`: 사용자 게임, 관리자 화면, API 라우트
- `components/ui/`: 실제 사용하는 공용 입력·버튼 컴포넌트
- `lib/`: 게임 규칙, UI 설정, 인증, 닉네임 및 통계 로직
- `migrations/`: Cloudflare D1 스키마 변경

## 이미지와 제작 도구

- `public/`: 운영 화면에서 직접 제공하는 최종 이미지
- `assets/source/`: 현재 이미지를 다시 만들 때 필요한 원본
- `scripts/`: 현재 자산 생성·최적화 도구
- `old/`: 런타임과 현재 제작 흐름에서 제외된 과거 자료

## 주요 게임 파일

- `lib/game-config.ts`: 공 개수, 투구 시간, 타격 기준
- `lib/game-ui.ts`: 화면 버전, 배트·결과 이미지와 효과 단계
- `lib/daily-bat.ts`: 일일 배트 지급과 점수 배율
- `app/page.tsx`: 화면 상태와 게임 진행 조정
- `app/api/game/route.ts`: 서버 판정과 점수 저장

기능을 수정할 때는 클라이언트와 서버가 공유하는 규칙을 `lib/`에 먼저 두고, 화면 파일에는 렌더링과 이벤트 연결만 남기는 것을 원칙으로 합니다.
