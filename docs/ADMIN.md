# 우땅 연구소 운영 안내

관리자 페이지는 `/admin`에 있으며 모든 운영 데이터 API는 관리자 인증 쿠키를 확인합니다. 일반 화면의 제작자 안내에서 부시시 우땅이를 다섯 번 눌러도 같은 로그인 화면으로 이동합니다.

## 비밀값

운영 암호와 세션 서명키는 소스나 `wrangler.jsonc`에 값을 넣지 않고 Cloudflare Workers Secret으로만 등록합니다.

```bash
wrangler secret put ADMIN_PASSWORD
wrangler secret put ADMIN_SESSION_SECRET
```

세션은 8시간 뒤 만료되며 `HttpOnly`, `Secure`, `SameSite=Strict` 쿠키를 사용합니다. 로그인은 같은 접속지에서 15분 안에 5회 실패하면 15분 동안 제한됩니다.

## 데이터 수집

- 타격마다 별도 통계 요청을 보내지 않습니다.
- 이미 저장하던 경기 세션의 요약 숫자만 함께 갱신합니다.
- 한 판이 끝날 때 `scores`, `daily_stats`, `daily_players`를 갱신합니다.
- 퍼널은 화면 진입이나 버튼 클릭 같은 주요 단계만 기록합니다.
- 관리자 대시보드는 일별 집계와 기간 인덱스를 우선 사용합니다.

## 전체 기록 초기화

`우땅야구 기록 전체 초기화` 문구를 직접 입력해야 실행됩니다. 랭킹, 경기 세션, 일별 통계, 퍼널, 닉네임 신고와 이전 D1 공유 카드 기록이 삭제됩니다. 금지어, 밸런스 기준, 로그인 제한 정보와 관리자 작업 로그는 보존됩니다. R2 공유 이미지는 버킷의 30일 수명 주기에 따라 자동 정리됩니다.

## 밸런스 설정

v1.1.0에서는 기존 타격 타이밍과 점수 판정의 안정성을 우선해 조회 전용입니다. 설정 테이블은 준비되어 있지만 게임 런타임은 배포된 상수를 계속 사용합니다.
