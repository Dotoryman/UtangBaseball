# v0.7.3 핫픽스 점검 기록

## 수정

- 공유 배경 JPG에 야구장 색이 바지 내부에 그려져 있던 원본 결함을 수정했다. CSS 투명도 문제와 구분했다.
- 기본 OG 이미지와 점수 카드가 모두 새 v073 배경을 사용한다. 과거에 저장된 공유 카드는 변경하지 않았다.
- 화면과 공유 카드의 `10구 승부`를 `야구 도전`으로 변경했다. 게임은 기존과 동일하게 공 10개로 진행한다.
- 로컬 랭킹의 날짜 기준을 한국 시간으로 통일하고, 화면을 켜 둔 상태의 자정 및 탭 복귀 시 갱신을 추가했다.
- 브라우저 저장소가 차단되어도 결과 화면과 서버 점수 저장이 진행되도록 보완했다.
- 다시 시작할 때 이전 공, 타격 결과, 캐릭터 동작을 초기화한다.
- 닉네임 입력 중 Space 키를 가로채지 않도록 하고 홈 버튼의 키보드 클릭을 지원한다.
- 공유 연속 클릭 방지, 이미지/업로드 대기 제한, 공유 앱 선택 상태 표시를 추가했다.
- 공유 이미지 로딩 실패 시에도 따뜻한 브라운 색상을 유지하고 긴 닉네임이 전광판을 넘지 않도록 제한했다.

## 이번 로컬 검증

- lint, TypeScript 검사 통과.
- 한국 시간 23:59:59 → 00:00:00 경계 계산 검사 통과.
- 430px 너비 게임 영역에서 시작 화면, 카운트다운 3, 공 10개를 놓친 후 결과 화면을 직접 확인했다.
- 시작 화면 세로 입력/버튼, 5명 단위 랭킹, Dotoryman·v0.7.3 표기를 확인했다.
- 카운트다운 숫자·주인공·주변 이모티콘 겹침이 보이지 않았다.
- 결과 화면 이모티콘이 빈 원으로 나타나지 않고 주인공·점수·버튼과 분리되어 표시된다.
- 수정 OG 이미지와 투수 2프레임 스트립을 열어 흰 바지가 유지되는지 확인했다.
- 게임 배경·마운드 레이아웃은 이번 핫픽스에서 변경하지 않았다.

## 이전 요구사항 대조 및 남은 검증

- ABS 글자 제거/낮은 불투명도, 상태창 재설계, 결과 이모티콘 크기 충돌 수정은 v0.7.2 구현을 유지한다.
- 타격 성공 직후 들어오는 공을 제거하고, 실패 시 캐치 시점에 제거하는 기존 분기 유지.
- 공유 페이지 최초 HTML의 OG 메타, 일반 링크 방식 PLAY BALL, 공유 이미지의 0바이트 응답 수정은 유지한다.
- 실제 카카오톡 앱에서의 소개이미지 렌더링, 모바일 Safari의 전체 애니메이션과 공유 동작은 이번 환경에서 미검증이다.
- 운영 빌드 재개 후 모든 라우트와 배포 파일 생성 완료. 종료 시 Windows libuv assertion은 재현됐지만 Wrangler dry-run은 통과했다.
- 2026-09-05 운영 배포 완료: `51104f92-c5e7-4554-8404-22ac61680b03`. 운영 첫 페이지 HTTP 200, v0.7.3 및 새 OG 경로를 확인했다.
